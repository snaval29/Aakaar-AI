## 💻 2. Hardware & Software Requirements

- **Operating System:** Windows 10/11 (64-bit), Ubuntu Linux, or macOS
- **GPU:** NVIDIA GPU with at least 4 GB VRAM (RTX 3050, 3060, 4060, etc.) strongly recommended
- **Python:** Python 3.10, 3.11, or 3.12 ([Download Python](https://www.python.org/downloads/))
- **Node.js:** Node.js v18 or v20 ([Download Node.js](https://nodejs.org/))
- **Git:** Git for Windows / Linux ([Download Git](https://git-scm.com/))
- **FFmpeg (Required by Whisper/librosa for audio loading):**
  - **Windows:** In PowerShell run: `winget install Gyan.FFmpeg` (or download from [ffmpeg.org](https://ffmpeg.org))
  - **Ubuntu/Debian:** `sudo apt update && sudo apt install -y ffmpeg`

## 📦 3. Complete Step-by-Step Dependency Installation

### Step 3.1: Clone the Repository
Open Command Prompt, PowerShell, or Terminal:

```bash
git clone https://github.com/snaval29/Aakaar-AI.git
cd Aakaar-AI
```

---

### Step 3.2: Install All Python Backend Dependencies

#### A. Install PyTorch with NVIDIA CUDA GPU Support
If your friend's laptop has an **NVIDIA GPU**, run:

```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
```
*(If the laptop does NOT have an NVIDIA GPU, install standard CPU PyTorch by running: `pip install torch torchvision torchaudio`)*

#### B. Install Audio, AI Models, and Web Server Libraries
Run:

```bash
pip install transformers accelerate soundfile librosa openai-whisper fastapi uvicorn python-multipart pydantic nest-asyncio pyngrok
```

#### What each Python package does:
- `torch`: PyTorch tensor computing framework for deep learning models.
- `transformers`: Hugging Face library used to run Meta's **MusicGen-Small** (`facebook/musicgen-small`).
- `accelerate`: Enables optimal GPU memory offloading and fast inference.
- `soundfile`: High-performance C-based WAV file read and write library.
- `librosa`: Audio signal processing, pYIN fundamental frequency extraction, and MIDI note conversion.
- `openai-whisper`: Speech-to-text model for timestamped lyric transcription.
- `fastapi`: High-performance asynchronous web API framework.
- `uvicorn`: Lightning-fast ASGI production web server.
- `python-multipart`: Required for streaming audio uploads (`multipart/form-data`).

---

### Step 3.3: Install Frontend Dependencies & Build the Web UI
Navigate into the `frontend/` folder, install the packages, and build the static assets:

```bash
cd frontend
npm install
npm run build
cd ..
```

#### What each Node.js package does:
- `react` & `react-dom` (v19): Component rendering and reactive state management.
- `vite` (v8): Blazing fast bundler that compiles the React app into `frontend/dist/`.
- `@vitejs/plugin-react`: Fast Refresh support for React in Vite.

## 🚀 4. How to Run the Unified Server

Once dependencies are installed, **run the single master command from the repository root (`Aakaar-AI/`)**:

```bash
python server.py
```

### What happens automatically:
1. Detects your NVIDIA GPU (`Using device: cuda:0`).
2. Loads **MusicGen** model weights into GPU memory.
3. Loads **Whisper** speech transcription model into GPU memory.
4. Mounts the compiled React Web UI from `frontend/dist/`.
5. Starts the web server on port `8000`.

### Open the Application:
Open your browser and visit:
👉 **`http://localhost:8000`**

- **Feature 1 (Text-to-Music):** Type a description (e.g. *"cinematic piano with soft violin"*), select duration (5–15s), and click **Generate music**. Listen and download the `.wav` file.
- **Feature 2 (Scale Predictor):** Upload an audio file, choose the time range, and view real-time transcribed lyrics mapped note-by-note with detected musical scale!

## 🌐 5. How to Share It Over the Internet (ngrok)

If your friend is hosting the server on their laptop and you want to use it from your own laptop or phone:

1. Download **[ngrok](https://ngrok.com)**.
2. Run ngrok in a second terminal window on your friend's laptop:
   ```bash
   ngrok http 8000
   ```
3. ngrok will output a public HTTPS link:
   ```text
   Forwarding   https://xyz-subdomain.ngrok-free.dev -> http://localhost:8000
   ```
4. Anyone on any computer can open `https://xyz-subdomain.ngrok-free.dev` and use Aakaar AI!

## ⚙️ 6. Important Laptop Power Settings (For 24/7 Hosting)

If using a laptop as a server:
1. **Prevent Sleep When Lid is Closed:**
   - On Windows: *Control Panel → Power Options → "Choose what closing the lid does"* → Set both battery & plugged-in to **"Do nothing"**.
2. **Keep Charger Plugged In:**
   - Laptop GPUs automatically throttle and drop to low-power mode when running on battery. Keeping the charger plugged in ensures 100% full-speed music generation.
